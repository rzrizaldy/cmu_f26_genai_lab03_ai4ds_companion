Lab 03 · Which reminder should we send next?

Generative AI Lab · Fall 2026 · Friday 13 November 2026 · prepared by Rizaldy Utomo (TA)

Today we play the notification team at a language app. We work with real Duolingo reminder logs and real app reviews. Gemma writes our code, Jev reads text for us, and we check everything before we decide. About 40 minutes, follow-along, with one open prompt of your own at the end.

Step 1: pick where to run it

A. Google Colab (easiest)

  1. Download lab03_starter.zip from the Google Drive link in the Canvas announcement (sign in with your Andrew account), and unzip it. Keep the zip file too.
  2. Go to colab.research.google.com, choose File → Upload notebook, and pick lab03_ai4ds.ipynb from the unzipped folder.
  3. Run the first code cell. When it asks for a file, upload the original lab03_starter.zip. A normal CPU runtime is enough.

We ran the notebook from the unzipped folder with no key and got zero errors. If Colab gives you trouble, switch to option B or ask in the Zoom chat.

B. Your own laptop

pip install -r requirements.txt

Then open lab03_ai4ds.ipynb from the unzipped folder in Jupyter or VS Code.

Step 2: a Gemini key (optional)

No key? No problem. Every example still runs, using Gemma answers we saved ahead of time.

To try your own prompts, add a key named GEMINI_API_KEY:

  • Colab: click the 🔑 icon on the left, add the secret, and turn on notebook access.
  • Laptop: set it as an environment variable before you start Jupyter.

Nobody needs a TypeSafe key. We ran Jev once and saved its answers.

About A–L and the made-up wording

The released logs only call the reminders A–L. Duolingo never published the text behind each ID. To make them easier to picture, we gave each one made-up wording, such as A "🔥 Your streak is on the line!" and G "Keep your streak going with a lesson." You'll see a 🎭 next to it. The numbers are real; the words are not, so please don't read the results as "urgent beats gentle".

The message cards on the "What learners actually see" slide are different: those are real, published Duolingo messages, each linked to its source.

What these data can't tell us

  • There is no "no reminder" group, so we can't say reminders beat silence.
  • There are no user IDs, so our intervals can't account for the same learner showing up twice.
  • Predicting who finishes a lesson doesn't tell us which reminder causes it.
  • The reminder logs (2020) and the reviews (2025) come from different people and years. We connect the steps, not the learners.
